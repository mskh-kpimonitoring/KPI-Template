# 📖 Lumina 3D Flipbook Reader
**ระบบจำลองการเปิดหนังสือ 3 มิติ สำหรับเอกสาร "เล่ม.pdf" (571 หน้า)**  
ออกแบบตามมาตรฐาน **UI/UX Pro Max** & Modern Web Performance

---

## 🚀 วิธีเปิดใช้งาน (Quick Start)

สามารถเลือกเปิดใช้งานได้ 2 รูปแบบตามความสะดวก:

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์ `run_flipbook.bat` (แนะนำสูงสุด ⭐)
1. ดับเบิ้ลคลิกไฟล์ **`run_flipbook.bat`** ในโฟลเดอร์นี้
2. ระบบจะเริ่มทำงาน Local Static Server ขนาดเล็ก (Zero-dependency ผ่าน PowerShell) และเปิดบราวเซอร์แสดงผลทันทีอัตโนมัติ
3. หน้าเอกสาร `เล่ม.pdf` (571 หน้า) จะถูกโหลดขึ้นมาพร้อมแอนิเมชันเปิดหน้าหนังสือ 3 มิติ

---

### วิธีที่ 2: เปิดไฟล์ `index.html` โดยตรง
1. ดับเบิ้ลคลิกไฟล์ **`index.html`** ด้วย Google Chrome, Microsoft Edge หรือ Brave
2. หากบราวเซอร์ตั้งค่าความปลอดภัยไม่ให้ดึงไฟล์อัตโนมัติ จะมีหน้าต่าง **Drag & Drop** สีเข้มสวยงามปรากฏขึ้น
3. ลากไฟล์ **`เล่ม.pdf`** มาวางที่หน้าต่าง หรือคลิกเพื่อเลือกไฟล์ ตัวอ่านจะเริ่มทำงานทันทีโดยไม่มีปัญหา CORS

---

## ✨ จุดเด่นและการออกแบบ (Key Features)

### 1. ⚡ Virtualized Lazy-Rendering & LRU Cache (รองรับเอกสาร 571 หน้าได้ลื่นไหล)
- **ไม่กินแรม**: เอกสารขนาดใหญ่ 571 หน้า หากเรนเดอร์พร้อมกันจะใช้แรมนับกิกะไบต์ แต่ระบบนี้ออกแบบด้วย **Dynamic Window Buffer & LRU Cache** โดยจะเรนเดอร์เฉพาะหน้าปัจจุบันและหน้าข้างเคียง (Memory footprint คงที่ประมาณ 40–70 MB เท่านั้น)
- **คมชัดระดับ Retina/4K**: คำนวณ `window.devicePixelRatio` แบบไดนามิก ทำให้ตัวหนังสือภาษาไทยและรูปภาพในเล่มคมกริบ ไม่แตกเบลอ

### 2. 📚 แอนิเมชัน 3D Flipbook & เสียงเปิดหน้าสมจริง (Audio Synthesizer)
- ใช้เอนจิน **StPageFlip** จำลองการโค้งงอของกระดาษ, เงาสันหนังสือ (Book Spine), และเงาตกกระทบสมจริง
- ระบบเสียงเปิดหน้าหนังสือสังเคราะห์ผ่าน **Web Audio API** (ไม่ต้องโหลดไฟล์เสียง MP3 ภายนอก ทำงานได้ 100% แม้ไม่มีอินเทอร์เน็ต)
- สามารถเปิด/ปิดเสียงได้ด้วยปุ่มลำโพงบนแถบเมนู

### 3. 🎨 4 ธีมระดับพรีเมียม (UI/UX Themes)
- 🌙 **Midnight Obsidian** (ธีมมืดสุขุม คอนทราสต์สูง สบายตา)
- 📜 **Warm Parchment** (โทนกระดาษถนอมสายตา สีอุ่น สไตล์ห้องสมุดคลาสสิก)
- 🌲 **Emerald Luxury** (โทนเขียวมรกตหรูหรา เหมาะกับงานวิชาการ/รายงานระดับสูง)
- ☀️ **Clean Studio** (ธีมสว่าง คลีน มินิมอล โมเดิร์น)

### 4. 🧭 ระบบนำทางและสารบัญเจาะลึก 428 รายการ (Interactive TOC)
- **สารบัญฉบับสมบูรณ์ (Full PDF Table of Contents)**: สกัดข้อมูลจากสารบัญตัวจริงในเล่ม PDF ครบถ้วน **428 รายการ** (ประกอบด้วย KPI 128 ตัวชี้วัด, OKR 297 ตัวชี้วัด, หน้าปก, คำนำ และสารบัญ)
- **ระบบค้นหาด่วนแบบ Real-time**: มีช่องพิมพ์ค้นหาตัวชี้วัดหรือคำสำคัญ (เช่น "Sepsis", "Stroke", "มะเร็ง", "KPI 10") กรองผลลัพธ์ทันทีขณะพิมพ์
- **แท็บปุ่มกรองประเภท**: เลือกดู `[ ทั้งหมด (428) ]`, `[ เฉพาะ KPI (128) ]`, `[ เฉพาะ OKR (297) ]`, หรือ `[ ส่วนนำ ]` ได้อย่างรวดเร็ว
- **คลิกเลือกหน้าได้ทันที**: เมื่อคลิกรายการใดในสารบัญ ตัวอ่านจะพลิกหน้าไปยังเนื้อหาของตัวชี้วัดนั้นทันทีอย่างแม่นยำ พร้อมไฮไลต์หน้าปัจจุบันอัตโนมัติ
- **แถบเลื่อน (Scrubber Slider)** พร้อม Tooltip พรีวิวเลขหน้า
- **ช่องพิมพ์เลขหน้า** พิมพ์เลขหน้าที่ต้องการแล้วกด `Enter` เพื่อกระโดดไปหน้านั้นทันที
- **แผงภาพตัวอย่างทุกหน้า (Thumbnails Filmstrip)** เรนเดอร์ภาพตัวอย่างเฉพาะหน้าที่เลื่อนผ่านด้วย `IntersectionObserver`
- **ที่คั่นหน้าและโน้ตย่อ (Bookmarks & Notes)** บันทึกหน้าที่อ่านค้างไว้และจดโน้ตย่อ บันทึกคงอยู่ในบราวเซอร์ผ่าน `localStorage`

### 5. 🔍 ระบบซูมและควบคุมมุมมอง
- ย่อ/ขยายได้ตั้งแต่ 100% ถึง 250%
- ดับเบิ้ลคลิกเพื่อซูมเข้า/รีเซ็ต
- ขณะซูม สามารถคลิกลาก (Pan / Drag) หน้าหนังสือได้อย่างอิสระ
- สลับโหมด **หน้าคู่ (2-Page Spread)** หรือ **หน้าเดี่ยว (Single Page)** ได้ด้วยปุ่มเดียว

## ⌨️ ปุ่มลัดคีย์บอร์ด (Keyboard Shortcuts)

| ปุ่ม | คำสั่งการทำงาน |
| :--- | :--- |
| **`→`** หรือ **`PageDown`** | พลิกไปหน้าถัดไป |
| **`←`** หรือ **`PageUp`** | พลิกกลับหน้าก่อนหน้า |
| **`Home`** | ไปหน้าแรกสุด (หน้าปก) |
| **`End`** | ไปหน้าสุดท้าย (ปกหลัง) |
| **`Space`** | เริ่ม/หยุดการเล่นเปิดหน้าอัตโนมัติ (Auto-flip Slideshow) |
| **`F`** | เปิด/ปิดโหมดเต็มจอ (Fullscreen) |
| **`T`** | เปิด/ปิดแถบภาพตัวอย่าง (Thumbnails) |
| **`C`** | เปิด/ปิดสารบัญ (Table of Contents) |
| **`B`** | เปิด/ปิดที่คั่นหน้า (Bookmarks) |
| **`+`** / **`-`** | ซูมขยาย / ย่อขนาด |
| **`0`** | รีเซ็ตขนาดเป็นพอดีหน้าจอ |
| **`Esc`** | ปิดหน้าต่างพาเนลทั้งหมด / ออกจากโหมดซูม |
